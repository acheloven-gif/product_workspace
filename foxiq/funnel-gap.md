# FoxIQ: обещания воронки memoryOS → что есть в приложении

Дата: 2026-10-22. Решение Наташи: воронку memoryOS копируем на FoxIQ **один в один, вместе с темой памяти**; дизайн пока не меняется.
Источники: обещания воронки по шагам — `foxiq/memoryos-promises.md`; что есть в FoxIQ — `foxiq/app-now.md` (обход 2026-10-22).
Идеи общего улучшения FoxIQ сюда не входят — они в `foxiq/hypotheses.md`.

В FoxIQ память — одна из 7 категорий: игра Fox Memory (найти пары карточек) и модуль Memory в треке (10 уроков на этой игре).

**Итог:** есть — 6, частично — 4, нет — 13.
Есть оболочка ежедневной привычки: короткая сессия, серия, награды, безлимит в подписке. Нет самого продукта, который продаёт воронка:
обучения техникам запоминания, дворцов памяти, интервальных повторений, личного плана и видимого роста памяти.
