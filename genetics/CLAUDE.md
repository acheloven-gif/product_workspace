# Генетика / генеалогическое древо — анализ рынка

Сессия — «Эдмунд · Генетика». Стадия: идея, анализ рынка (поручение Наташи, 2026-10-26).

## Задача

Анализ рынка приложений по генетике и генеалогическому древу, чтобы решить, стоит ли делать своё приложение и какое.

## Что сделать

1. Карта рынка: ключевые игроки (генеалогия — Ancestry, MyHeritage, FamilySearch, Geni и др.; ДНК-тесты — 23andMe, AncestryDNA,
   MyHeritage DNA, Nebula и др.; приложения-«древа», ИИ-фото предков, «узнай происхождение по фото/лицу» и т.п.).
   Для каждого: что продаёт, модель монетизации, цены, гео, оценка выручки/загрузок (Sensor Tower / AppMagic / открытые данные), рейтинг.
2. Кто из них льёт платный трафик через веб-воронки (квиз → пейволл): FB Ad Library, сервис FB-выгрузок (`reports/`), лендинги. Пройти 2–3 воронки до пейволла.
3. Сегменты и тренды: что растёт (ИИ-реставрация фото, говорящие портреты, «этническое происхождение по лицу», семейные истории), что падает
   (ДНК-тесты после проблем 23andMe), юридические риски (генетические данные, GDPR, медицинские обещания).
4. Ниши для нас: 3–5 идей приложения под нашу модель (веб-воронка + подписка, без физических ДНК-китов), с оценкой
   спроса, конкуренции, сложности разработки и рисков.
5. Итог — `genetics/market-analysis.md`: таблица конкурентов, выводы, рекомендация 1–2 идей для обсуждения с Катей.

## Правила

- Результаты — файлами в `genetics/`, нейтрально-деловым языком (уйдёт Кате).
- Анализ — по правилам корневого CLAUDE.md: источники, период, метки «Видно в данных / Предположение / Не знаем»; не выдумывать цифры.
- В ClickUp ничего не менять без согласия Наташи.
