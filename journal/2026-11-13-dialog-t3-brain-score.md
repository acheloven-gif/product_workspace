# 2026-11-13: T3, пересдача и Brain Score (решение Наташи)

- **[FoxIQ / T3, Brain Score]** После обсуждения пересдачи (план Корюна, [комментарий](https://app.clickup.com/t/1249d35ptku?comment=1200990000360786)) решение Наташи: пересдача обязательна. Балл будет оставаться IQ и считаться по формуле: исходный IQ (137 / 120 / 104 из воронки) × Brain Score. Brain Score = коэффициент посещаемости приложения + успешность прохождения IQ-теста приложения. Сертификат обновляется по мере изменения IQ, пользователю предлагается скачать новый; есть история изменения IQ с разными сертификатами. При долгом отсутствии балл снижается; не должен зависеть только от ответов теста. Brain предлагал вместо этого не называть балл IQ и не менять сертификат (риск возвратов и вводящего в заблуждение результата), Наташа решила оставить IQ. Открыто: точная формула Brain Score, диапазон, подпись «оценка» на сертификате, нужна ли отдельная задача вне T3. — Brain
