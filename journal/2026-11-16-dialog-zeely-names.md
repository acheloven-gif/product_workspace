# 16 ноября 2026: названия для Zeely-клона

Наталья попросила собрать варианты названия из задачи и новые в одном HTML-файле, с происхождением слов и проверкой. Vendlio исключён по ответу Кати от 12 ноября. Отдельный блок отсева не нужен.

По просьбе Натальи повторно проверены 22 названия из общей таблицы. Найдены важные совпадения: Bandio уже есть в App Store; PromoGen.ai близок к Promgena и создаёт AI-рекламу; BANDUO используется для рекламного товара; Adgena и Adlora работают в смежной продуктовой нише. У Proclamo три слога, а не четыре, как ранее ошибочно указал Brain. Вариант остаётся предварительным, юридическая чистота не установлена.

Проверка USPTO/EUIPO не завершена: результаты по именам недоступны. Проверка сторов и языковых ассоциаций ограничена, диктант на слух не проводился. Некоторые статусы доменов не подтверждены; ответ RDAP 404 не гарантирует доступности для покупки.
