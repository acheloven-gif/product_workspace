# memoryOS-клон — контекст проекта

Стадия: **идея → готовим ТЗ**. Своё название продукта пока не выбрано. Сессия проекта — «Селеста · memoryOS».

## Что копируем

**memoryOS** — тренировка памяти в игровом формате: запоминать имена, детали, иностранные слова; геймифицированные микроуроки.
- Веб-воронка: `start.memoryos.com` (рекламодатель в FB — Flyer 1 VC).
- Приложение: [memoryOS: Memory Games](https://apps.apple.com/us/app/memoryos-memory-games/id1553283646) (Encoder Inc., 4.87★, 16.8K оценок US); Android — [Google Play](https://play.google.com/store/apps/details?id=com.memoryos.app) (4.8★, 13.4K отзывов, 100K+ установок).
- Разбор воронки и приложения со скриншотами: `references/memoryos/`. Цены воронки: 4 нед $15.19 → $49.99; 12 нед $36.99 → $99.99; 24 нед $59.99 → $119.99.
- Подход как у Charisly: копируем воронку → план → приложение конкурента, свой дизайн и бренд.

## Почему выбрали (анализ выгрузок Facebook, лист «Шорт-лист»)

- Вертикаль «IQ, память, мозг» растёт: спенд 28 дней $1.1M (июль) → $5.8M (август) → $7.3M (10.10).
- memoryOS: спенд 28 дней ≈ $0.51M в срезе 10.10, тренд «держится»; гео tier-1 (US 72%, GB 7%, IT 7%, TR 7%, PL 6%);
  один из самых дешёвых CPA в выгрузках.
- Продвигается от лица персонажей-«экспертов» (Brian Calloway); крючок объявления: «memoryos combines gamified micro lessons…».
- Источник: `reports/fb-kandidaty-itog-10-10.xlsx`, `reports/fb-shortlist.html`.

## Важно учесть

- **Не использовать слово «Memory» в названии, подзаголовке, иконке и метаданных.** У команды уже был прецедент: App Review по претензии
  Ravensburger (товарный знак «Memory» в Германии) — игру Memory Cards переименовали в Card Match везде, не только для DE.
- Обещания про «улучшение мозга/IQ» формулировать аккуратно, без медицинских заявлений (риск отказа в App Store и в рекламе Meta).

## Как писать ТЗ (как для Charisly)

- Образец формата — ТЗ Charisly: [Charisly — веб-приложение для прокачки харизмы](https://app.clickup.com/t/1249d35gb2w)
  (Блок 1 «Каркас»: таб-бар, вход и пейволл, экраны, контент, тренажёры, границы; Блок 2 «Сценарий после воронки»).
  Образцы Кати: [Ridwan](https://app.clickup.com/t/1249d35f07g), [Nalumi](https://app.clickup.com/t/1249d35ccm7), [FoxIQ](https://app.clickup.com/t/1249d35af8t).
- По экранам; формальное ТЗ, не макет — решения по реализации за разработчиком.
- Скринкаст конкурента прикладывать к задаче на разработку.
- Разработчики сдают с доказательством самотеста (скрин, запись, события в аналитике). PostHog с первого дня.
- ТЗ идёт Кате на проверку. Сценарий после воронки — зона Никиты, апсейлы — Дани (см. корневой CLAUDE.md).
