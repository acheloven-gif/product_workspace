# FB-выгрузки: методика пересчёта (с 27.10, по комментарию Кати от 21.10)

- Строки с лендом в сторе (apps.apple.com / itunes / play.google) не суммировать со строками с веб-лендом: в сторе «конверсия» — установка.
- В сводной рядом с CPA — колонка «куда ведёт реклама (схема)».
- CPA = спенд 28д / «количество конверсий» из выгрузки (не восстанавливать конверсии из округлённого CPA).
- Агрегировать только внутри одной схемы; несколько строк одного приложения — показывать отдельно.
- Скрипты пересчёта: `agg.py` (агрегаты по приложению × месяц × схема), `rebuild.py` (пересчёт `reports/fb-kandidaty-itog-10-10.xlsx` → `reports/fb-kandidaty-itog-27-10.xlsx`; пути внутри — абсолютные, поправить при запуске).
