Воронка, одно определение

Люди, проекты foxiq_ff и azora_ff, один и тот же фильтр тестовых почт. Первый экран — funnel_start. Первый вопрос — screen_index = 1. Пейволл — экран с id ровно paywall или Paywall, без экранов отказа и без cta_skip_paywall. Оплата — funnel_purchase_success. Так считается и FoxIQ, и Azora.

Почему прошлый пересчёт Azora дал 47,1% / 9,1% / 4,3%. Он брал любой экран, в чьём id есть слово paywall, включая отказы, и не снимал тестовые почты. С определением выше окно версии 3.2 (17.10–02.11) даёт FoxIQ 28% / 7,0% / 2,0% и Azora 46% / 7,8% / 3,6%. Оплаты сошлись точно: 63 и 694. На пейволле остаётся несколько человек против напечатанных 897 и 8 893.

Вход без оплаты

Баг, не продуктовое решение. Экран cta_skip_paywall или failed_payment_message: 315 человек. У 47 тот же person_id потом получил subscription_started. У 268 — нет. В проекте приложения из этих 268 видны 264: приложение открыли 50, игру 19, тест 11, урок 7, сертификат 0, пейволл в приложении 44. Воронка и приложение часто заводят разных людей на одну почту, поэтому 50 — нижняя граница.

Поведение

Записи есть. API записей и таблица raw_session_replay_events: 530 записей, 418 id. Пустая выборка в первой выгрузке была из-за другого фильтра таблицы, не потому что записей нет.

До 12.10 записей 41 у 30 id. Из 16 ранних покупателей Primer запись есть у 15. У одного нет ни записи, ни событий — путь неизвестен. У шести есть события приложения, но нет subscription_started. Воронки FoxIQ до 16.10 в PostHog нет, поэтому ранний квиз по событиям не восстановить.

Злые тапы (3 нажатия в одну точку за 1,5 с) заново не считались: в метаданных записи есть число кликов, но не место и не интервал. Цифра версии 3.2 остаётся: 4 из 62, период до 3.11. Медиана активного времени 42 секунды — тоже до 3.11. Новое среднее по 257 записям покупателей после 12.10 — 195 секунд активности; это среднее, не медиана, и со старой цифрой его не смешиваю.

Неделя сломанного меню в выборке остаётся. По событиям PostHog, не по первому часу: 28 покупателей, игру открыли 8, тест 3, урок 2, сертификат 11, отмену нажали 3. Это отдельный блок, не норма поведения.
