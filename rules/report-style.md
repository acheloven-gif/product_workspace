# Правила оформления отчётов

Решение Наташи (17.11.2026). Применять к любому новому отчёту (недельный, продуктовый разбор, аудит) без напоминания.

## Общая идея
Нежный, персиковый, милый вид, но серьёзное содержание. Милота только в цвете, скруглениях и воздухе. Данные и текст — деловые: без шуток, мемов, мультяшных шрифтов и кучи эмодзи.

## Цвета
| Роль | Цвет |
|---|---|
| Фон страницы | `#fff5ee` |
| Карточка | `#fffdfb` |
| Текст | `#3a2a26` |
| Приглушённый текст | `#8b6f65` |
| Граница | `#f4d9cb` |
| Акцент (активная вкладка, кнопки) | `#e48a6c` |
| Фон чипов и шапок таблиц | `#fde3d6`, `#fdebe1` |
| Заголовок страницы | `#7a3f2c` |
| Хорошо / внимание / проблема | `#5f9c7a` / `#c9922f` / `#c9604f` |

Контраст текста на фоне должен быть читаемым: белый текст только на акценте `#e48a6c` в жирном начертании.

## Форма и шрифты
- Системный шрифт (`-apple-system`, `Segoe UI`, `Roboto`, `Arial`), без декоративных.
- Карточки: скругление 16px, мягкая тень того же персикового оттенка. Вкладки и чипы: полностью скруглённые.
- До 900 px ширины, воздух между блоками.

## Что нельзя
- Подсказок при наведении (требование Кати).
- Скрывать важное в свёрнутые блоки: гипотеза, вариант, метрика, защитная метрика, объём и срок, как посчитан срок — всё видно сразу.
- Данные без периода и выборки: у каждой цифры «N из M» и даты.
- Красный или яркий цвет без смысла (только для проблем, с легендой).

## Вкладки (еженедельный отчёт)
- Вкладки недель слева направо по хронологии: старые слева, новая справа.
- Файл всегда открывается на самой новой неделе.
- Табы только на CSS (radio + соседние селекторы), без JavaScript: предпросмотр вложений в ClickUp скрипты не запускает.
- В теле: что сделано, тесты, блокеры, план, решение Кати. Только то, что делала сама Наташа (без трафика и подписок FoxIQ).

## Перед отправкой
Открыть файл в браузере и проверить: таблицы не обрезаются, вкладки переключаются, текст читаем.
