# Правила оформления отчётов

Решение Наташи (17.11.2026, дополнено 18.11.2026). Применять к любому новому отчёту (недельный, продуктовый разбор, аудит) без напоминания.

## Главное (18.11): графики вместо текста
- Минимум текста. Тяжёлый для чтения отчёт — неудачный отчёт.
- Всё, что можно показать графиком или диаграммой, показывать графиком: сравнение недель (парные столбцы/полосы), динамика по дням (линия или столбцы), воронки (сужающиеся полосы), распределения по времени (составные полосы), доли (кольцо/полоса).
- Таблицы только для точных цифр, которые нельзя прочитать с графика. Сырые таблицы «события по дням», «покупатели по дням Primer/PostHog» в отчёт не кладутся (они для проверки, их место в методике).
- Графики только на чистом CSS/inline SVG, без JavaScript и внешних библиотек (предпросмотр вложений ClickUp скрипты не запускает). Цвета из палитры ниже: прошлая неделя — приглушённый персиковый, текущая — акцент.
- На каждом графике: заголовок, подписи «N из M» на столбцах, период, одна короткая строка под ним (что видно). Малая выборка (меньше 30): штриховка/пометка на столбце.
- «Главное» вверху: не больше 3 коротких строк. Длинные описания к каждой строке, длинные «проверено до расчётов», определения метрик и повторяющиеся пояснения — в файл методики (.md) рядом, в HTML только ссылка на неё.
- Гипотезы: короткий список, по одной строке, с пометкой «гипотеза, не подтверждена данными».

## Форма и шрифты
- Системный шрифт (`-apple-system`, `Segoe UI`, `Roboto`, `Arial`), без декоративных.
- Карточки: скругление 16px, мягкая тень того же персикового оттенка. Вкладки и чипы: полностью скруглённые.
- До 900 px ширины, воздух между блоками.

## Что нельзя
- Подсказок при наведении (требование Кати).
- Скрывать важное в свёрнутые блоки: гипотеза, вариант, метрика, защитная метрика, объём и срок, как посчитан срок — всё видно сразу.
- Данные без периода и выборки: у каждой цифры «N из M» и даты.
- Красный или яркий цвет без смысла (только для проблем, с легендой).

## Вкладки (еженедельный отчёт)
- Вкладки недель слева направо по хронологии: старые слева, новая справа.
- Файл всегда открывается на самой новой неделе.
- Табы только на CSS (radio + соседние селекторы), без JavaScript.
- В теле: что сделано, тесты, блокеры, план, решение Кати. Только то, что делала сама Наташа (без трафика и подписок FoxIQ).

## Перед отправкой
Открыть файл в браузере и проверить: графики не обрезаются, на узком экране читаются, вкладки переключаются, текст читаем.
