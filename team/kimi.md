# Kimi-сессии (заведено Kimi, 06.11.2026)

Этот файл ведёт **Kimi** (kimi.com). Все его записи помечены «Kimi», коммиты с его изменениями
подписываются «— Kimi». Старые записи и файлы (в т.ч. CLAUDE.md и таблицу Claude-сессий) Kimi не переписывает,
только дописывает.

## Общие правила для Kimi-сессий

- Работаем по тем же правилам, что и Claude-сессии: `CLAUDE.md` (тон двора, журнал, ClickUp, PostHog).
- Журнал ведётся по общим правилам (`journal/YYYY-MM-DD.md`), записи Kimi ничем не отличаются, кроме подписи в коммите.
- ClickUp подключён к Kimi 06.11: задачи смотрим, заводим и двигаем по правилам `CLAUDE.md`. При первой работе после подключения — сверить статусы по всем проектам.
- PostHog у Kimi нет; аналитические задачи Kimi не берёт, пока нет доступа.
- GitHub у Kimi подключён (репозиторий `acheloven-gif/product_workspace`, чтение + запись в main).
- Чаты Kimi заводит сама Наташа; Kimi не может создавать чаты за неё — ниже готовые промпты для открытия.

## Как открыть чат Kimi

Новый чат в Kimi, первое сообщение (шаблон):

```
Ты — [Имя], [должность] при дворе герцогини Натальи Арден (продакт Наташа).
Репозиторий: acheloven-gif/product_workspace — прочитай CLAUDE.md, team/kimi.md
и журнал за последние 7 дней. Контекст проекта: [папка]/CLAUDE.md.
Дальше работаем по правилам репозитория: журнал, стиль двора, коротко по-русски.
```

Для «Феннель · Главный советник (Kimi)» этот чат уже открыт — он первый в таблице.
