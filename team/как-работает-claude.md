# Как работает Claude в воркспейсе Наташи

Краткая инструкция. Полные правила — `CLAUDE.md` в корне репозитория; при расхождении главный он.

## 1. Где и чем

- Claude Code в браузере (claude.ai/code), репозиторий `acheloven-gif/product_workspace`.
- Контейнер одноразовый: всё сохраняется только через commit + push в `main`. Перед записью — pull (параллельно работают другие сессии).
- Память между сессиями: `CLAUDE.md` (правила), `journal/` (журнал по дням), папки продуктов, `playbook/`, `reports/`, `team/`.
- Подключено: ClickUp, GitHub. PostHog — через прямой API (ключ только в секретах окружения).

## 2. Сессии

- Одна сессия на продукт или зону, плюс общие: Феннель (главный советник), Ренье (задачи), Вивиан (отчёты), Изольда (аналитика) и слуги по продуктам. Таблица с ID — `CLAUDE.md` → «Сессии».
- Все сессии пишут в один журнал. Феннель видит остальные сессии и передаёт им поручения — только по просьбе Наташи.

## 3. Задачи в ClickUp

Основа — гайд Кати `team/claude-для-продакта.md`, раздел 5: любая новая задача, в каком бы виде она ни пришла, сразу становится карточкой в ClickUp. Как в гайде: задачи коллегам Claude сам не создаёт, сначала предлагает.

**Когда заводятся сами, без вопроса:**
- Наташа даёт поручение Claude («проведи анализ», «напиши ТЗ», «разбери конкурента») → карточка в её списке «Продуктовые задачи Наташа» (in progress), потом работа, результат — в карточку, статус → complete или in review.
- Задача прозвучала на созвоне, в чате, на скрине, в расшифровке → свои заводятся сразу в список Наташи; задачи исполнителям (в пространство продукта: WEB, IOS, FF, Запуск продукта) — сначала предложение, после «да» заводятся.
- «Поставь задачу» (в том числе коллеге) → ставится сразу, разрешение не переспрашивается.
- Решили брать новое приложение → карточка в «Проектах» (стадия «идея»).
- После заведения — короткий доклад: что заведено, ссылки.

**Без карточки:** короткие ответы в чате — справка, текст сообщения, «что по задачам».

**Только с согласия Наташи:** удаление и архивация задач, удаление файлов и вложений.

**Как оформляются:**
- одна карточка = один результат за один подход;
- название с проектом первым словом: «Charisly: …»;
- описание по шаблону **Проект / Что сделать / Результат**;
- перед созданием — поиск дублей;
- у задачи исполнителю один исполнитель и весь контекст в карточке.

**Статусы** Claude двигает сам по контексту: из разговора, комментариев, скринов понятно, что задача начата / сдана / в тесте / готова / отменена → перевод, запись в журнал, короткий доклад. Неочевидно — один вопрос.

**Карточка продукта** в «Проектах» всегда актуальна: любая новость (домен, почта, ссылки, платёжки, задачи исполнителям) сразу дописывается в свой блок, отмечается пункт чек-листа. Пароли и доступы — только в ClickUp, не в репозиторий.

## 4. Журнал

- `journal/YYYY-MM-DD.md`, ведётся автоматически: решения, сдвиги по задачам, новости, договорённости и сроки.
- Строка: `- **[Проект]** что произошло. → следующее действие. (ссылка на задачу)`.
- Не пишутся: технические детали, цифры анализа, пароли.
- В начале разговора о задачах — журнал за 7 дней: напомнить про незакрытое, предложить двинуть карточки.

## 5. Аналитика

- Только реальные данные, всегда период, выборка, часовой пояс, люди или события; метки «Видно в данных / Предположение / Не знаем».
- Тестовые пользователи исключаются; веб и iOS не смешиваются; срезы — гео, источник, поведение, с воронки / мимо.
- Гипотезы — от проблемы и данных; объём теста — расчётом (α = 5%, мощность 80%); метод (A/B или «до и после») — с обоснованием.
- Под выводом — как считали. Правила PostHog — `playbook/posthog.md`, образец разбора — `playbook/analytics-example/`.

## 6. Люди и тексты наружу

- К кому с чем — таблица в `CLAUDE.md` → «Люди». Не знаем, к кому, — один раз спросить Катю и дописать.
- Задачи, комментарии, сообщения коллегам, ТЗ, отчёты Кате и журнал — нейтрально-деловым тоном. С Наташей — в стиле двора.
- ТЗ Наташа утверждает сама, Кате на проверку не отправляет.
- Отчёт за день: 3–5 коротких пунктов простым языком.

## 7. Недельный ритм

- Понедельник: план и фокус недели → в журнал.
- Пятница: что сделали, что переносим.
- «Собери отчёт за сегодня» → что сделала, что мешает, что нужно от Кати.
