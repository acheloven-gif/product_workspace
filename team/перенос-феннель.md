# Перенос воркспейса: что сделано и как устроено (сессия «Феннель · Главный советник»)

Краткая памятка на случай переноса аккаунта. Подробности — `CLAUDE.md`, `journal/`, папки продуктов.

## Как устроено

- **Репозиторий** `acheloven-gif/product_workspace` — единственная память между сессиями: `CLAUDE.md` (правила), `journal/` (журнал по дням), папки продуктов, `playbook/`, `reports/`, `team/`.
- **Сессии Claude Code (claude.ai/code)** — по одной на проект, таблица и ID в `CLAUDE.md` → «Сессии». При переносе ID сессий не переедут: завести новые сессии с теми же названиями и дописать новые ID в таблицу.
- **Коннекторы:** ClickUp (работает), GitHub (репозиторий). PostHog MCP в `.mcp.json` берёт ключ из `${POSTHOG_API_KEY}`, но не подключается (CONNECTION_CLOSED); аналитика идёт через прямой API PostHog (HogQL, `/api/projects/1/query/`). Ключ — только в настройках окружения (секреты), не в репозиторий.
- **Доступы и пароли** — только в карточках ClickUp.

## Как поднять на новом аккаунте

1. Подключить GitHub-аккаунт `acheloven-gif` и дать Claude доступ к репозиторию `acheloven-gif/product_workspace` (основной с 30.10; старый `ekaasrirahmawati403-bit/product-workspace` больше не ведётся).
2. Подключить ClickUp (Settings → Connectors).
3. Добавить ключ PostHog в секреты окружения (`POSTHOG_API_KEY`), разрешить сеть до `ph.app-inkfolio-reader.pro`.
4. Завести сессию «Феннель · Главный советник» с этим репозиторием; первым сообщением — «Ты Феннель. Прочитай CLAUDE.md, team/перенос-феннель.md, team/как-работает-claude.md и журнал за 7 дней».
5. Феннель заводит слуг по таблице из `CLAUDE.md` и вписывает новые ID.
6. Переписка старых чатов не переносится — всё нужное должно быть в журнале и файлах.
