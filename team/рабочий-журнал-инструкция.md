# Рабочий журнал в Claude: как настроить у себя

Идея: Claude сам ведёт файл-журнал по датам. В любом чате, где ты обсуждаешь задачи, решения,
запуски или новости по работе, он без просьбы дописывает строку в файл сегодняшнего дня.
Потом можно спросить «что я делала на этой неделе» или «что мы решили по X», и он отвечает по журналу.
Это страховка от «забыла», и готовая основа для дейлика и недельного отчёта.

Работает только в **Claude Code** (вкладка Code в десктопном приложении Claude или `claude` в терминале).
В обычных чатах claude.ai это не работает, там нет доступа к файлам.

## Шаг 1. Папка для журнала

Создай папку, например `~/Desktop/Рабочий журнал/`. Внутри ничего создавать не нужно,
Claude сам заведёт файл `ГГГГ-ММ-ДД.md` при первой записи.

## Шаг 2. Глобальные правила

Файл `~/.claude/CLAUDE.md` читается Claude Code в начале каждой сессии в любой папке.
Если его нет, создай. Если есть, допиши блок ниже в конец. Подставь своё имя и путь к папке.

Проще всего попросить сам Claude Code: «создай файл ~/.claude/CLAUDE.md вот с таким содержимым»
и вставить текст ниже.

```markdown
# Глобальные правила (действуют во всех проектах и чатах)

Пользователь — [Имя], продакт. Общение по-русски, коротко.

## Рабочий журнал — вести автоматически, без напоминаний

Папка: `/Users/[логин]/Desktop/Рабочий журнал/`. Один файл на день: `YYYY-MM-DD.md`.
Это страховка от «забыла»: в любом чате, как только речь заходит о задачах, процессах или работе,
записывать туда факты сам, не спрашивая разрешения и не дожидаясь просьбы.

**Что записывать** (одна строка на событие, без времени):
- обсудили задачу / приняли решение;
- сделали или сдвинули что-то по задаче (включая действия в ClickUp: создали, закрыли, перенесли);
- новость по работе: запустили трафик, закончили тест, кто-то что-то сдал, появился блокер;
- договорённости с людьми (кто что должен) и сроки, если названы.

**Формат строки:** `- **[Проект или область]** что произошло. → следующее действие, если есть. (ссылка на задачу ClickUp, если есть)`

**Что НЕ записывать:** технические детали запросов, промежуточные шаги, аналитические цифры.
Журнал — про задачи и решения, а не про данные.

**Как вести:**
- Файл дня создавать при первой записи, заголовок `# YYYY-MM-DD`. Дописывать в конец, не переписывать.
- Перед записью прочитать файл сегодняшнего дня, не дублировать уже записанное.
- В начале разговора о задачах/планах прочитать журнал за последние 7 дней и опираться на него:
  напомнить про незакрытое, спросить про статус, предложить двинуть карточки в ClickUp.
- Если упомянут факт, меняющий состояние в ClickUp (запуск, конец теста, задача сделана), записать
  в журнал и либо двинуть карточку самому, либо прямо сказать, какую карточку двинуть.
```

Путь к папке должен быть полным, с `/Users/логин/`, а не `~`. Узнать логин: в терминале `whoami`.

## Шаг 3. Проверить

Открой новый чат в Claude Code в любой папке и напиши что-то рабочее, например
«завела задачу на ТЗ по харизме, срок четверг». Потом посмотри в папку: должен появиться
файл с сегодняшней датой и одной строкой.

Если файла нет, спроси Claude: «ты прочитал ~/.claude/CLAUDE.md? что там про журнал?».
Обычно проблема в пути к папке.

## Как пользоваться

- **Дейлик:** «что я делала вчера и позавчера, коротко для дейлика».
- **Конец недели:** «что я сделала на этой неделе, что перенесла».
- **Вспомнить решение:** «что мы решили по ценам в Charisly».
- **Отчёт Кате в конце дня:** «собери отчёт за сегодня: что сделала, что мешает, что нужно от Кати».

## Необязательно, но полезно

**Подключить ClickUp.** В настройках Claude (Settings → Connectors) подключи ClickUp. Тогда Claude сможет
сам заводить карточки, менять статусы и читать твои задачи. В `CLAUDE.md` допиши абзац про свой
список задач, например:

```markdown
## Мои задачи в ClickUp

Мои задачи — список «[название]» в пространстве «[название]». Одна карточка = один результат,
который можно сделать за один подход. Задачи коллегам самостоятельно не создавать — сначала предложить.
```

**Убрать запросы разрешений.** Если Claude постоянно останавливается и спрашивает «можно ли»,
создай файл `~/.claude/settings.json`:

```json
{
  "permissions": {
    "defaultMode": "acceptEdits"
  }
}
```

`acceptEdits` разрешает правки файлов без вопросов, но команды в терминале всё ещё спрашивает.
Это безопасный вариант для старта.
